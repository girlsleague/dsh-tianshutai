## ✨ 项目简介

**天枢台**是一款为 DSH（DeepSeek Harness）打造的专业级传统命理可视化工作台插件。它把四柱八字、紫微斗数、倪海厦《天纪》医理与现代大数据可视化技术融合在一起，让古典命理从晦涩的口诀变成一张张清晰、精美、可交互的星图。

无论你是零基础的好奇者，还是沉浸多年的专业研究者，都能在这里找到属于自己的观察视角。

## 🌟 核心功能

### 1. 高精度四柱八字排盘
- **真太阳时校准**：内置全国省市经纬度数据库，自动计算经度差、年际均时差，并自动识别 1986–1991 年的中国夏令时。
- **四柱全景卡片**：天干地支大字、十神、地支藏干（本气/中气/余气）、纳音、十二长生星运、六十甲子空亡。
- **五行能量量化**：天干 1.0、藏干 0.6/0.3/0.1、月令 ×2.5 的启发式权重模型，输出 0–100 的日主旺衰评分。
- **可视化图表**：五行环 Donut 图、日主旺衰 Gauge 仪表盘、十神能量条形图、十二神煞命中矩阵。

### 2. 大运流年深解
- 虚岁 1–80 岁的人生运势波形曲线图。
- 八步大运卡片，点击展开**每步大运的通俗深度解读**（运势总评 / 事业机运 / 财富避坑 / 处世心法）。
- 十年流年轮盘，岁运并临与天克地冲重点标注。

### 3. 关键流年事件推演（附行动锦囊）
- 自动回溯 2012–2026 年的历史流年大事推演。
- 每个凶煞/冲克年份均配备 **「⚡ 天枢化解锦囊」**，把宿命的焦虑转化为可执行的应对动作（主动应冲、破财消灾、立愿应劫等）。
- 支持用户“准 / 部分准 / 不准”反馈，实时计算模型历史拟合度。

### 4. 普通用户最关心的现实场景（白话命书）
1. 💰 **搞钱与财富模式**：正偏财格局、行业赛道契合度评分榜、合伙雷区、资产配置策略。
2. 💖 **婚恋与正缘**：伴侣长相性格速描、正缘相识场景、感情暗礁化解、黄金成家窗口年份。
3. 🌿 **体质健康调摄**：倪海厦《天纪》杀星脏腑对应法、生命周期易感岁运预警、四季食疗膳方。
4. 📅 **12 个月流月晴雨表**：按月吉凶评分与具体的职场/财务/情感应对策略。
5. 🔮 **赛博开运方案**：幸运穿搭色、吉利方位、幸运数字、佩饰与办公居家风水细节。

### 5. 紫微斗数十二宫全盘
- 基于倪海厦《天纪》教学体系，传统十二宫回字形排布。
- 十四主星庙旺利陷、生年四化（化禄 / 化权 / 化科 / 化忌）。
- 点击任意宫位，在侧栏展开该宫的星宿解析与《紫微斗数全书》原文考证。

### 6. 双人合盘（合婚 / 商业合伙）
- 天干夫妻正合、地支六合、五行互补度、夫妻宫刑冲害的量化分析。
- 输出契合度得分、天作之合利好点与相处暗礁磨合点。

### 7. 一键生成「赛博命运使用说明书」手机长图
- Canvas 离线绘制 9:16 手机壁纸级海报，含命运型号、命格配置、避坑锦囊与开运磁场。
- 一键保存高清长图，适合朋友圈 / 小红书分享。

### 8. 本地隐私档案库
- 所有生辰数据完全保存在用户本机的 `data/profiles.json`，绝不上传云端。
- 支持一键保存、载入、切换并增删改查。

### 9. 问命盘师（AI 智能对话）
- 侧边抽屉式交互，针对当前命盘实时答疑。
- 每条回复自动附带《滴天髓》《穷通宝鉴》《三命通会》或倪师《天纪》的原文引证卡片。

### 10. 四套国风主题 + 双模切换
- 🖤 玄墨赛博 / 🌲 青绿山水 / 👑 赤金朱砂 / 📜 素雪宣纸。
- ✨ 小白人设（通俗白话）/ 🧭 专家罗盘（全量参数）一键切换。

## 📦 安装方式

### 方式一：从 GitHub 直接安装（推荐）
在 DSH 终端或插件管理面板执行：
```bash
dsh plugin install github:girlsleague/dsh-tianshutai
```

### 方式二：从 Release 压缩包安装
```bash
dsh plugin install https://github.com/girlsleague/dsh-tianshutai/releases/download/v2.0.0/dsh-tianshutai-2.0.0.tgz
```

### 方式三：本地源码运行
```bash
git clone https://github.com/girlsleague/dsh-tianshutai.git
cd dsh-tianshutai
pip install lunar_python
python server/app.py
```
然后浏览器访问 `http://127.0.0.1:58765`。

## 🛠 技术栈

- **后端**：Python 3（标准库 `http.server` + `lunar_python` 万年历引擎）
- **前端**：原生 HTML / CSS / JavaScript（零构建依赖，SVG + Canvas 绘图）
- **命理算法**：真太阳时校准、藏干权重旺衰、十二神煞、大运逆推、四化飞星、合盘五行互补
